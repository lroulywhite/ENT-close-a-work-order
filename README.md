# ENT | Complete and Close a Work Order [Simulation]

Guided click-through simulation for Momentus Enterprise, built for the Learning Center course "Work Order Management Basics" (lesson: Complete and Close a Work Order).

Live page (after enabling GitHub Pages): https://lroulywhite.github.io/ENT-complete-close-work-order/

## What it covers
- Complete work orders from the Edit Event page (right-click, Tools, Complete Work Orders)
- What happens to open work order items when an order is completed
- Open the Edit Work Order page (right-click, Edit, Edit Work Order)
- Complete a work order from the Edit Work Order page (Actions, Tools, Complete Work Orders)

## Embed in Genially (HTML/Code widget)
The simulation is a 1920x1166 stage (product screen plus checklist bar) that scales to fit. Use a 1920:1166 box and recommend full-screen mode.

```html
<iframe src="https://lroulywhite.github.io/ENT-complete-close-work-order/"
  title="Complete and close a work order simulation"
  style="width:100%;aspect-ratio:1920/1166;border:0"
  allowfullscreen></iframe>
```

## Files
- `index.html`: the whole simulation (self-contained: fonts, styles, product screens, and scripts are inline; it makes no network requests)
- `.nojekyll`: tells GitHub Pages to serve the file as is

## Source and UI version
Product screens come from Enterprise demo captures dated 2026-10-23 (snapshot `enterprise-2026-10-v1`, kept outside this repo). When the product UI changes, recapture the screens and rebuild rather than editing `index.html` by hand.

## Not covered (not captured)
The Actions menu with Tools closed, and any screen after Complete Work Orders is selected.
